# Шаг 09 — Native overview

Дата: 2026-10-12. База: `319bc80`. Ветка: `codex/uad-netlify-step08`.

## Результат

По прямому выбору пользователя согласованный обзор перенесён из iframe в React-компоненты общего app.html. Сохранены четыре карточки, динамика (линия/столбцы/таблица), участники (количество/доля), последствия, сравнение земель (полосы/таблица) и методика. Ограниченная область 1190 px; ниже динамики колонки 45/55: слева участники → последствия, справа земли. На узком экране одна колонка.

Показатели динамики и земель независимы. Для линии количества выбранной земли используется индекс 2020=100 с Германией как ориентиром; столбцы показывают абсолютные числа выбранной территории от нуля. Нормированные показатели используют точный числитель с участием Pkw и средний зарегистрированный парк по двум концам года. Пересечение участников, различие ДТП/людей и ограничения нормирования объяснены в UI.

Год и территория приходят из AppShell. Клик по земле меняет общий контекст обзора и URL. «Показать на карте» в общем header сохраняет прежнюю семантику передачи года/земли и остальных фильтров карты. Обзор после первого визита остаётся смонтированным, поэтому локальные представления графиков/таблиц не сбрасываются при переключении разделов. Полный reload сохраняет контекст через существующий shell-storage, но сбрасывает представления к default, как прежде.

В AppShell один раз при первом визите в обзор читается существующий `public/analytics/overview.json` (26 038 байт), валидируется схема, суммы, 119 снимков автопарка и совпадение generation с каталогом. Ошибка обзора имеет отдельный retry и не выдаётся за готовый экран. Полные годовые файлы и workers карты для обзора не создаются. Набор данных и подготовительные скрипты не менялись.

## Изменённые области

- `src/app/NativeOverview.jsx`: карточки/пояснение, выбор представлений, SVG-график с ResizeObserver, таблицы, участники/последствия/земли/источники.
- `src/app/overview-model.js`: общие вычисления, сортировка, абсолютная/индексная динамика и сравнение с предыдущим годом.
- `src/app/overview.css`: согласованная компактная раскладка, доступный focus, локальная прокрутка таблиц.
- `src/app/AppShell.jsx`: общий набор обзора, нативный экран, iframe только для времени/тяжести, корректная поясняющая подпись.
- `tests/native-overview.test.mjs`: числовые сценарии всех 102 срезов, индекс против абсолютных столбцов, отсутствие ложного роста при пропусках/нулевом знаменателе.

Лаборатория размещения и исходные HTML-макеты сохранены для обсуждения. Кнопки перестановки и варианты лаборатории не перенесены в продуктовый обзор. Время/тяжесть остаются адаптерами iframe. Их перенос — отдельные шаги 10/11.
