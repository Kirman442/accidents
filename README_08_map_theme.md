# Дополнение после шага 08 — тема карты

Дата: 2026-10-12. База: `8080a2b`. Ветка: `codex/uad-netlify-step08`.

В общем закреплённом header после «Показать на карте →» добавлен выбор «Тема карты»: Тёмная / Светлая. На экране карты он остаётся доступным после года. По умолчанию используется CARTO Dark Matter, светлый вариант — CARTO Positron, по URL пользователя. Выбор сохраняется в localStorage (`uad-map-theme`); при недоступном хранилище переключение работает в текущем приложении.

AppShell передаёт только подложку в существующий FilterMap: карта не перемонтируется, загрузчик, кеш, фильтры, координаты камеры и карточка не зависят от темы. Самостоятельные диагностические страницы сохраняют прежнюю подложку. Добавлена возможность сжатия мобильного меню и select, чтобы header оставался в ширине экрана.

Проверки: 53 существующих Node-теста прошли с `--test-isolation=none` (обычный запуск в ограниченной среде получает spawn EPERM); ESLint изменённых JSX и production build прошли. Прежнее предупреждение loaders.gl о spawn сохраняется. В браузере проверены обе реальные подложки, 273 007 ДТП 2025, сохранение карточки/кольца и кеша 27.16 МиБ при переключении, отсутствие повторного пересчёта, переход в обзор и сохранение темы после reload. Ошибок console нет. Узкий экран проверяется при 390×844; физический телефон не проверен.

Это дополнение к оболочке после шага 08. Шаг 09 (перенос обзора из iframe) не начат. Push/deploy и настройки БД не выполнялись.
