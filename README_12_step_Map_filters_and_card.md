# Шаг12 — Фильтры карты и отдельная карточка

Дата2026-10-13. Базаb2f1f41. Веткаcodex/uad-netlify-step08. Пользователь согласовал реализацию, затем commit/push/deploy.

## Реализовано

- Фильтры «Ситуация ДТП» и «Характер столкновения» по существующим accident_pattern/accident_type. Множественный выбор OR внутри поля, AND между полями; счётчики исключают ограничение собственного поля. Общие подписи разделены с карточкой.
- Реальный React HourGrid6×4 с тумблерами рядов00–05/06–11/12–17/18–23. Все24часа по умолчанию. Нажатия, клавиатура и протягивание работают по согласованной модели; изменения worker-отбора только после pointerup. Пустые часы дают0ДТП, включая запрос окрестности. Очистка и полный сброс различаются: сброс возвращает24часа.
- Полная ссылка с версионированным mf{v:2,filters}, годом/землёй. Копирование и прямая ссылка/резервное поле при недоступном clipboard. Общая оболочка сохраняет исходный mf до canonical URL replace, восстанавливает на первом визите и popstate. Ссылка содержит отбор, без камеры/выбранной точки. Старая sessionStorage hour[] мигрируется как прежнее All, новое хранилищеv2 сохраняет настоящий пустой выбор.
- Карта использует доступную ширину, карточка — соседняя колонка около70/30 с clamp340–440px. При viewport≤1100 карточка ниже карты; самостоятельная прокрутка. Существующие остальные аналитические экраны ограничены1190px.
- В карточке действия отбора конкретной ситуации/характера, два режима50м: текущие фильтры или все условия выбранного года в текущей территории. Исходное ДТП исключается. Можно открыть соседа вне маски карты с явным пояснением; фильтры не меняются, кольцо сохраняется. «К исходному ДТП» возвращает начальную карточку после цепочки соседей. Год/территория и освобождение источника остаются ограничениями выбора.
- Сдвигающее сообщение обновления счётчиков ранее удалено. При browser-проверке исправлено перекрытие flyout статическим header: открытый filterbar находится выше header. Это устранение недоступных кнопок, общий UI/UX не перерабатывался.

Режим участников «хотя бы один» отложен; копирование координат не добавлялось. Источники/Arrow/Parquet, БД/Supabase не менялись. Модель часов вынесена в src/files/hours-selection.js, отдельный исторический mockup сохранён.
