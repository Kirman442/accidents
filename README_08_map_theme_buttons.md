# Дополнение после шага 08 — кнопки темы карты

Дата: 2026-10-12. База: `00216d0`. Ветка: `codex/uad-netlify-step08`.

По уточнению пользователя список тем заменён двумя кнопками в общем скруглённом блоке: луна (Dark Matter) и солнце (Positron). Образец — переключатель справа вверху локального charging-points. В UAD блок расположен в общем header после «Показать на карте →», а на карте после года. Активная кнопка выделена; обе имеют aria-label, aria-pressed, title и видимый клавиатурный focus. Перед заменой списка пользователь сообщил, что значение меняется без изменения карты. Замена на кнопки выполнена по прямому запросу, без утверждения о доказанной причине.
