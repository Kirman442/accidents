# Подготовка карты — mockup выбора часов

Дата2026-10-13. Базаb7bf015. Веткаcodex/uad-netlify-step08.

## Согласованный эксперимент

Отдельный рабочий mockup `prototypes/map-hours-lab.html`: сетка6столбцов×4строки и тумблеры рядов Ночь00–05, Утро06–11, День12–17, Вечер18–23. Оформление минимальное, общий UI/UX отдельно. Основная карта пока не использует новый контрол и сохраняет старые быстрые периоды; перенос после просмотра.

Нажатие часа переключает его. Протягивание задаёт последовательный диапазон между началом и концом, даже через строки и в обратном направлении. Старт на выключенном часе добавляет диапазон, на выбранном снимает. Другие часы сохраняются. Промежуточный draft отображается, подтверждение только pointerup. Pointercancel, потеря capture, Escape/blur отменяют незавершённый жест. Тумблер частичного ряда добавляет недостающие часы, полного ряда снимает все6. Состоянияfalse/mixed/true доступны через rolecheckbox; внешний вид тумблера. КлавиатураTab/Enter/Space работает независимо от протягивания. Начальный выбор — все24часа; кнопка очистки показывает пустой выбор. Через полночь — два диапазона, например22–23 и00–05.

Здесь нет от/до полей и пересчёта ДТП: это проверка самого механизма выбора. Пустой выбор явно обозначает отсутствие выбранных часов; при переносе требуется согласовать его с текущим worker-контрактом, где пустой массив означает отсутствие ограничения. Модуль map-hours-lab-model.js отделяет диапазоны/ряды/подписи от DOM.
