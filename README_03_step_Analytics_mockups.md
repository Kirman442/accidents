# Шаг 03 — Analytics mockups

Дата: 2026-10-11. Ветка: `codex/uad-file-benchmark`. База: `1f77084`.

## Результат и границы

Сохранены отдельные автономные HTML-макеты: `prototypes/overview-mockup.html` (стартовая общая ситуация) и `prototypes/time-mockup.html` (время и сезонность). Они предназначены для согласования экранов перед реализацией. Код существующих файловой карты и загрузчика в этом шаге не изменён. Ранее предложенный шаг «расчёты по фильтрам» отложен пользователем до определения аналитики; номер 03 использован для фактически выполненного этапа проектирования.

Меню переключает обзор и время. Территория и год передаются в URL; из периода в обзор передаётся конечный год. Отдельные разделы «Тяжесть и условия» и «Карта ДТП» пока обозначены в меню. Кнопка перехода на карту поясняет будущую передачу параметров; карта нескольких лет ещё не согласована. Перекрёстная фильтрация по ячейкам не реализована: нажатие показывает точное значение.

Время и сезонность: Германия/земля, начальный/конечный год, все ДТП или участие одной из шести групп. Четыре блока — месяц, почасовой профиль будней/выходных, день недели × час, год × месяц. Режимы количества, среднего за календарный день и доли. Почасовой профиль всегда нормирован на число будних/выходных календарных дней; его единицы отдельно подписаны. Годовая матрица всегда показывает все шесть лет, выбранный период выделяется.

## Данные и проверки

Совместные агрегаты подготовлены на десктопе из 1 543 886 строк `UAD_data/prepared-2020-2025/accidents_YYYY.csv`, без изменения исходников. Группы участников пересекаются. Для каждого из 6 × 17 × 7 срезов суммы месяцев и ячеек равны числу ДТП; число ДТП для всех групп сверено с исходными годовыми/земельными сводками. Для всех участников также сверены отдельные месяцы, часы и дни недели. Встроенный набор сохраняет SHA-256 шести использованных CSV.

Воскресенье исходника = 1; понедельник = 2. На экране порядок Пн–Вс. Календарные знаменатели рассчитываются в UTC, учитывая високосные годы. Месячные доли относятся ко всему выбранному периоду; доли в годовой матрице — к каждому отдельному году. Деление на календарные дни оценивает частоту зарегистрированных ДТП, а не риск поездки.

Подготовленный JSON содержит 382 980 байт и встроен в HTML второго экрана: макет открывается без отдельных файлов данных и без Supabase. Это размер данных макета, не оценка будущего стартового набора продукта. Встроенный обзор также использует реальные сводки.

Браузерная проверка: Германия 2025 — 273 007 ДТП; NRW, велосипедисты, 2020–2025 — 109 796 ДТП; ячейка Пн 00:00 для этого среза — 55 исходных ДТП. Переключение на среднее выводит 0,18 на один понедельник. Германия 2020 — 650,26 ДТП за календарный день (237 994 / 366). Проверены переключение долей, два направления меню, подписи и выбор точной ячейки. На ширине 390 px горизонтальное переполнение страницы отсутствует; широкие матрицы прокручиваются внутри секций. Размер браузера восстановлен.

## Кандидаты и следующие решения

`docs/analytics-candidates.md` — пополняемый реестр C01–C16. Первый пункт: необычные изменения по территориям и месяцам. Каждая идея содержит ограничения, предполагаемый экран и статус. Кандидаты не являются утверждёнными задачами реализации.

Далее согласовать экран времени, затем содержание «Тяжесть и условия», поведение карты и распределение кандидатов. Общий механизм запросов и расширение предагрегатов проектировать после выбора аналитики. Включение макетов в рабочее приложение и публикация — отдельные этапы.

## Открытие и архив

Можно открыть HTML прямо с диска, сохранив оба файла рядом. Для меню через HTTP запустить в корне проекта `python -m http.server 5188 --bind 127.0.0.1`, затем открыть `/prototypes/time-mockup.html`. Текущий просмотр согласования доступен через отдельный локальный сервер: `http://127.0.0.1:5188/time-mockup.html`.

После коммита полный снимок проекта: `powershell -NoProfile -File scripts/package-step.ps1 -Step 3 -Name Analytics_mockups`. Архив `UAD_data/03_step_Analytics_mockups.zip`, рядом SHA-256 и снимок экрана. Точный commit внутри `STEP_SNAPSHOT.txt`. Исходные данные и локальные настройки исключены; небольшие встроенные агрегаты макетов являются публичной производной частью прототипов.
