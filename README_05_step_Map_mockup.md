# Шаг 05 — Map mockup

Дата: 2026-10-11. Ветка: `codex/uad-file-benchmark`. База: `efebdda`.

## Результат

Четвёртый экран `prototypes/map-mockup.html` — отдельная карта с настоящими точками Unfallatlas, выбором года и земли, закреплённым header и панелью предложенных фильтров. Все четыре макета связаны меню. Переходы из времени и тяжести сохраняют территорию, период и участника. На карте реально применяются только территория и один год; сохранённый контекст явно поясняется и возвращается в аналитику. Дополнительные фильтры и карточка ДТП не реализованы: это элементы для обсуждения.

`FilesApp.jsx` получил режим `mapOnly=1&year=2025&land=0` с проверкой диапазонов входных параметров. Он использует существующий FileLoader, четыре workers и реальные буферы координат, отображает прогресс и количество, позволяет повторить ошибочную загрузку. Обычная файловая страница сохраняет прежний интерфейс. Общий движок фильтрации не менялся. C18 «Сравнения и рейтинги» записан как отложенный кандидат.

## Проверки

Сборка завершилась, ESLint изменённого компонента прошёл, все 30 существующих тестов прошли. JavaScript четырёх HTML проверен отдельно. В браузере проверены: Германия 2025 — 273 007 ДТП; Nordrhein-Westfalen 2025 — 61 521; 2020 — 49 328. Переход карта → тяжесть и обратно сохраняет регион, период 2020–2025 и Pkw, с явным пояснением неприменённых параметров. На ширине 390 пикселей горизонтального переполнения страницы нет; после прокрутки header.top=0, notice уходит вверх. Сборка сохраняет известное предупреждение loaders.gl о browser-external spawn.

## Запуск и ограничения

Для живого локального макета нужны два сервера: обычный HTTP-сервер каталога `prototypes` (здесь порт 5188) и собранная файловая версия Vite preview на порту 5187 с базовым путём `/accidents/`. Адрес iframe в HTML намеренно локальный: `http://127.0.0.1:5187/accidents/files.html`. Подготовленный набор хранится отдельно в `UAD_data`; настройка источника — по инструкции файловой версии. Это локальный прототип, не готовая схема публикации.

Выбранный год загружается по всем 16 землям, отображается выбранная земля. При смене года/территории iframe пересоздаётся, поэтому кеш между такими переходами сейчас не сохраняется. Постоянный общий кеш и загрузка только выбранной земли — отдельное решение для интеграции экрана. Подложка CARTO требует сети. Точки пока не выбираются кликом; многолетняя карта, дополнительные фильтры, тепловой слой и карточка не реализованы.

Архив полного снимка исходников: `UAD_data/05_step_Map_mockup.zip`, сопровождается SHA-256 и STEP_SNAPSHOT с фактическим commit. Исходные данные, настройки, зависимости и сборка не входят в архив. Публикация и изменения Supabase не выполнялись.
