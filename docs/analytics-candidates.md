# Аналитика UAD — список кандидатов

Дата начала: 2026-10-11. Список пополняется в ходе обсуждения. Идеи в нём не являются утверждёнными задачами реализации. После обсуждения кандидат получает раздел, методику и приоритет либо остаётся отложенным. Идентификаторы сохраняем, новые идеи дописываем.

## Согласованная структура экранов

- Обзор: стартовая Германия, выбор земли/года, общие показатели, динамика, сравнение земель и структура ДТП.
- Время и сезонность: территория, период, участники; месяцы, день недели × час, будни/выходные, год × месяц. Сейчас отдельный HTML-макет.
- Тяжесть и условия: последствия ДТП, освещение и состояние дороги; третий HTML-макет для обсуждения.
- Карта ДТП: отдельный полноценный экран. Переход из аналитики сохраняет применимые параметры. Режим карты для нескольких лет пока не выбран.

## Как пополнять

Для каждой новой идеи фиксируем вопрос, необходимые данные, ограничения, предполагаемый экран (или «не определён») и статус. Наличие в списке не запускает разработку. Одобренные пункты переносим в спецификацию своего экрана, оставляя здесь ссылку/статус решения. Пока ничего из C01–C17 не утверждено к реализации.

Текущие макеты: `prototypes/overview-mockup.html`, `prototypes/time-mockup.html` и `prototypes/severity-mockup.html`. Фактическая реализация приложения и проектирование экранов учитываются отдельно в `docs/progress.md`.
