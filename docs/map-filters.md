# Правила карты — согласованы 2026-10-12

По умолчанию последний доступный год завершённого каталога, сейчас 2025. Переход из аналитики передаёт выбранный/конечный год и территорию; возвращение без явно заданного года использует последний выбор этой вкладки. Карта показывает один год. Многолетние исследования остаются на аналитических экранах.

## Отбор

Участники: Pkw, велосипедисты, пешеходы, мототранспорт, грузовые ТС, другие. Для каждой группы null — все; 1 — с участием; 0 — без участия. Между группами И. Присутствие двух групп не доказывает столкновения именно между ними.

Месяцы, дни, часы, последствия, освещение и дорога: пустой массив означает отсутствие ограничения. Внутри поля ИЛИ, между полями И. Последствия: с погибшими / тяжелоранеными / легкоранеными. Освещение: день / сумерки / темнота. Покрытие: сухо / мокро, влажно, скользко / зимняя скользкость. Тип дороги отсутствует и не подменяется состоянием покрытия.

Периоды суток в `src/files/map-query.js`: ночь 22–05, утро 06–09, день 10–15, вечер 16–21, включительно по часам. Все 24 часа покрыты ровно один раз. Зима — 12,1,2; весна — 3,4,5; лето — 6,7,8; осень — 9,10,11 выбранного года. Пресет заменяет набор своего фильтра. Снятие последнего значения возвращает «Все».

Исходный UWOCHENTAG: 1=воскресенье, 2=понедельник, …, 7=суббота. В меню порядок Пн–Вс; Будни выбирают 2–6, Выходные — 7,1. Подготовленные CSV сохраняют исходные коды. Кодировка сверена с [описанием данных статистических ведомств](https://download.statistik-berlin-brandenburg.de/d6480d95278a99fc/7a539fdf4985/AfSBBB_BE_LOR_Strasse_Strassenverkehrsunfaelle_2019_Datensatzbeschreibung.pdf).

## Счётчики

Возле опции — число ДТП при остальных ограничениях, без ограничения этого поля. Для участников исключается только условие конкретной группы; остальные группы сохраняются. Суммы разных фильтров не обязаны совпадать с итогом карты. Пока данные/пересчёт не завершены, нулевые опции не отключаются. После завершения невыбранные нулевые значения отключены; выбранный нулевой вариант можно снять. Пресеты, смена земли/года могут дать пустую выборку — показываем сообщение и сброс, выбор автоматически не меняем.

Обновление без «Применить». Esc и нажатие вне панели закрывают список. Workers возвращают маску и счётчики одним результатом; карта и итог обновляются вместе. Пока идёт новый запрос, явно обозначен прежний результат. Один запрос выполняется, промежуточные ожидающие состояния объединяются в последнее; старые ответы не публикуются.

## Память и жизненный цикл

Один экземпляр карты/загрузчика обслуживает переключения. Земля — отбор готовых данных, без перезагрузки iframe. Выбранный год загружается постепенно по всем 16 землям четырьмя workers. Другие годы только по запросу. LRU использует 100/32 МиБ; возврат к сохранённому году без скачивания. При вытеснении повторная загрузка допустима. В учёт добавлен резерв двух Uint8-масок на строку; GPU, временная распаковка и прочая память браузера вне бюджета удерживаемых буферов.

Выбор и фильтры сохраняются в sessionStorage этой вкладки. Исходные Arrow-таблицы/кеш живут в workers, не в sessionStorage: при полной перезагрузке страницы или уходе на другой отдельный HTML-экран память workers освобождается. Между такими страницами переносится выбор, а не бинарный кеш. Будущая интеграция экранов в единое приложение — отдельный этап.

Карточка ДТП, оформление и дополнительные показатели не входят в шаг 06. Карта остаётся локальным прототипом: HTML порт 5188, файловая версия и данные порт 5187. Канал postMessage проверяет origin и источник окна. Для отдельного просмотра карта доступна через files.html?mapOnly=1 с собственными годом/землёй.


Уточнение шага 08: внутри app.html переходы меню сохраняют смонтированную карту, кеш, фильтры и карточку. Самостоятельные legacy HTML по-прежнему имеют отдельный жизненный цикл. См. app-shell.md.
