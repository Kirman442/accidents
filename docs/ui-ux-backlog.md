# UI/UX — замечания для последующего согласования

## Агрегация карты и эксперимент с кластерами (14.10.2026)

Пользователь предпочёл hexagon для аналитического обзора больших территорий. Направление «Авто»: географические ячейки при отдалении, отдельные точки ScatterplotLayer при приближении. Тепловая карта — отдельный режим. Конкретный порог (например zoom10), размер/смена разрешения ячеек, легенда и цвета пока не утверждены — проверять на реальных данных. При отдалении укрупнять ячейки, учитывать все ДТП текущего отбора, не подменять агрегацию случайной выборкой точек. Пустые ячейки не нужны, подложка должна оставаться читаемой.

Кластеры записаны пользователем в эксперименты: группировка близких на экране ДТП в кружки с числами, раскрытие/приближение группы. Это отдельный кандидат для просмотра групп происшествий, не выбранный аналитический режим и не разрешение на реализацию сейчас. Не заменять принятую предпочтительность hexagon кластеризацией автоматически.

## Пояснение данных по режимам карты (14.10.2026)

Замечание пользователя: в «Что означают данные?» фраза «Одна точка — одно геокодированное ДТП с пострадавшими» относится только к режиму отдельных точек. Для больших площадей планируются hexagon/heatmap, точки — при приближении. При согласовании и подключении этих режимов сделать пояснение зависимым от текущего способа отображения: для точек — отдельное ДТП, для hexagon — агрегация ДТП в ячейке, для heatmap — смысл интенсивности согласно реально выбранному расчёту. Не обещать по тепловому цвету число ДТП или риск без соответствующего определения. Точная реализация, пороги масштаба и формулировки ещё согласовываются. Сейчас только запись замечания, без изменения макета или приложения.

## U01 — Карта не должна сдвигаться при открытии карточки

Замечание пользователя: появление карточки меняет ширину и сдвигает карту; такое поведение неудобно. Требование для будущей переработки: открытие/закрытие карточки и смена её содержимого не должны менять геометрию карты и положение рассматриваемого места на экране.

Предпочтение пользователя: постоянные две колонки уже при загрузке страницы, ориентир карта70%/информационная панель30%. Точное соотношение и ограничения ширины панели ещё согласовываем. До выбора ДТП панель может показывать информацию согласно текущему отбору; после клика — сведения о выбранном ДТП. Состав сводки, обновление по фильтрам, возврат к сводке после закрытия карточки и мобильное поведение ещё не утверждены.

Альтернатива для сравнения: карточка поверх карты, без изменения её размера. Пользователь предпочитает постоянную отдельную колонку.

Статус: записано, **не реализовывать пока**. Текущий step12 код и Netlify не меняются. Вернуться к U01 при постраничном обсуждении карты после общей темы.

## Невыбранные кнопки в «Последствия и условия» — учесть при переносе (14.10.2026)

Пользователь прислал Screenshot_5–7: в тёмной оболочке кнопки «Тяжёлые последствия, %», «С погибшими, %», «Матрица / Точки» в невыбранном состоянии имеют белый фон и почти белый текст. Это не disabled, а доступный невыбранный вариант.

Причина по CSS: src/app/severity.css задаёт .native-severity .ov-choices button {background:white}, перекрывая менее специфичное .shell-lab button {background:var(--panel)}. Цвет текста наследуется из тёмной оболочки; отдельный тематический override есть только для aria-pressed=true. При переносе общей темы явно использовать её переменные для фона, текста и границы всех невыбранных кнопок; проверить обычное, hover, выбранное и реально disabled состояния в обеих темах, включая эти две группы. Сейчас записано для переноса, CSS ещё не изменён.
