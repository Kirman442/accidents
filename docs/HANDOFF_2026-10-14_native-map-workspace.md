# Перенос согласованного экрана карты в приложение

14.10.2026. Пользователь разрешил перенос целиком: фильтры, сводка, карточка ДТП, постоянная панель и согласованные слои. Публикация и Git-коммит в этом запросе не запрошены.

## Реализовано

- `src/files/FilterMap.jsx`: постоянная область карты и панель 70/30, минимум панели 300 px; на узком экране панель ниже. Сводка / Фильтры / ДТП, место сообщений с сохранением высоты, краткие сообщения 3 секунды, ошибки сохраняются. Диагностика и кеш перенесены в раскрытие.
- `MapPanel.jsx`, `FilterIcon.jsx`, `map-workspace.css`: согласованные переключатели участников в двух колонках, сетка часов, сезонные ряды месяцев, Будни / Пн–Пт и Выходные / Сб–Вс, короткие категории кнопками, характер столкновения списком. Сохранение раскрытий; иконки активных условий и отдельный сброс каждого фильтра. Рабочий worker-отбор вместо макетных чисел.
- `map-query.js`: отдельные суммы трёх категорий среди действительно прошедших все фильтры ДТП. Самоисключающие фасеты для этого не используются. Во время загрузки сводка не выдаёт неполный итог за окончательный.
- `RecordCard.jsx`, `RecordIcons.jsx`: реальные сведения и разбор нескольких попаданий сохранены; участники и условия иконками, Pkw боковой силуэт, отдельные ситуация и характер столкновения. Явное приближение к ДТП, сохранение камеры при выборе/отборе. Окрестность 50 м удалена из основной карточки; «Анализировать это место» пока сообщает о будущем отдельном разделе, как согласовано.
- `map-layer-model.js`: фиксированный Hexagon GPU 1000 м, SUM веса 1, без экструзии; Авто / Ячейки / Точки / отдельная тепловая карта. Авто: точки от 10.2, обратно ячейки ниже 9.8. DPR deck.gl 1. Стабильные бинарные XYZ для агрегации и исходные XY+mask для точек; массивы не пересоздаются при движении камеры. Посещённые слои скрываются через visible вместо удаления. Цветовой диапазон ячеек 0–10000, 65% opacity, coverage .9; это текущие параметры переноса, не универсальный оптимум.
- `hexagon-picking.js`: исправленный центр с hexOriginCommon для deck.gl 9.1.8. Повторно проверить внутренний контракт при обновлении deck.gl.
- `AppShell.jsx`, `shell-state.js`, `theme.css`: общая тема приложения и карты; аналитика до 1190 px, обычные контролы 32 и header 36; мобильное меню. Общая территория, общий год карты/Обзора, отдельный общий период/участники Времени и Последствий. Год карты не обрезается по периоду аналитики. Явный переход из header аналитики передаёт конечный год и группу, временно заменяет подробные фильтры; есть возврат к графику и восстановление прежних фильтров. Восстановление касается подробных фильтров, без неподтверждённого восстановления общего года/территории/камеры.
- Исправлен конфликт белого фона невыбранных кнопок с текстом тёмной темы в Последствиях и условиях. Усилен приоритет тематических правил для production CSS, где порядок отличается от dev. Отдельный `files.html?mapOnly=1` сохраняет собственные селекторы и панель, через `map-standalone`.
