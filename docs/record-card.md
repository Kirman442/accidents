# Карточка ДТП — первый набор, 2026-10-12

Согласовано: лёгкая карточка, выбор/кольцо, время, последствия, отмеченные участники, условия, сценарий, место; раскрываемые другие ДТП в 50 м. Без пространственного индекса. Адрес не задерживает открытие. Похожие ДТП в административном районе — отложено, C19.

## Поля

Год/месяц/день недели/часовой интервал. Полная дата и минуты отсутствуют, не восстанавливаем их из UID. Последствия — текст и цвет, относятся ко всему ДТП, число погибших/раненых людей неизвестно. Участвовали — SVG-иконки с подписями только отмеченных групп, без вывода о том, какие группы непосредственно столкнулись. Освещение и покрытие показаны отдельными полями, включая день/сухо. Сценарий: UTYP1 (тип) и UART (вид происшествия), переведённые названия. Кодировка сверена с [официальным описанием](https://download.statistik-berlin-brandenburg.de/d6480d95278a99fc/7a539fdf4985/AfSBBB_BE_LOR_Strasse_Strassenverkehrsunfaelle_2019_Datensatzbeschreibung.pdf).

Место сейчас — земля и ссылка на координаты в OpenStreetMap. Адреса и названия населённых пунктов в загруженном наборе нет; справочник имён не подключён. В карточке это явно обозначено. Внешняя карта открывается только по нажатию пользователем; автоматического reverse geocoding нет. Открытие карточки полностью использует локальные загруженные данные.

record_id/source_uid/source_oid/plst/linref и прочие исходные служебные поля не отображаются. Внутренний ключ нужен для связи с точкой и исключения самой записи. Основной worker-ответ включает только год, землю, месяц, день недели, час, категорию, два сценария, свет, покрытие, отмеченные группы и координаты; никаких полных таблиц или массивов атрибутов на основной поток.

## Выбор

Клик: попадание 6 CSS-пикселей мышью, 10 для coarse/touch; не увеличивает сами точки. Включён GPU picking только актуальной маски. Один дополнительный слой рисует кольцо. Несколько точек возле клика — максимум 8 карточечных описаний; девятая сообщает «не менее 9», не выдумывает общий счёт. Выбор строки заменяет выбранную запись. Область попадания в пикселях не равна кругу 50 м.

Esc закрывает сначала открытый фильтр; следующий снимает выбор. Закрытие карточки или клик на пустое место снимает выбор. Панорамирование/масштабирование сохраняют выбор. При новом годе/неподходящей территории выбор снимается. При фильтрации он сохраняется, пока запись остаётся в маске; если скрыта — снятие с пояснением. Старые асинхронные ответы не возвращают закрытую/сменённую карточку. На узком экране карточка ниже карты, на широком рядом; окончательный UI/UX отложен.

## Окрестность

Считается только после раскрытия, по выбранному году, текущим фильтрам и территории, когда год и отбор полностью готовы. Исходная запись исключена; другие ДТП в тех же координатах остаются отдельными происшествиями. Круг центрируется на выбранном ДТП, не на координатах клика.

Без индекса: каждый worker последовательно читает координаты своих выбранных партиций. Географический bounding box отсекает далёкие точки, затем применяются остальные фильтры и расстояние Haversine на сфере радиуса 6371008.8 м. Результат включается при расстоянии ≤50 м. Учитывается переход долготы через 180°; фиксированные градусные радиусы не используются. Расстояния приблизительные: сфера вместо эллипсоида и округление источника до пяти знаков.

Полное число подсчитывается без накопления всех соседних объектов. Worker держит только ближайшие K≤100, основной поток объединяет ответы и показывает сначала 20. «Показать ещё» увеличивает видимый префикс на 20 до 100, повторяя ограниченный проход; при большем количестве общий счёт точный, ограничение списка явно указано. При смене записи блок закрывается; при смене фильтров раскрытая окрестность пересчитывается. Статистики других лет/районов автоматически не загружаются.

Пространственного индекса, новой библиотеки, базы или сетевого API карточки нет. Кеш исходных годов прежний; DTO и временный проход небольшие, служебные буферы picking, GPU и DOM карточки сверх бюджета удерживаемых буферов набора. Все 16 земель выбранного года уже обслуживаются существующими четырьмя workers.
