# UI/UX — согласованная тема и оболочка

13.10.2026. Пункт 2 согласован пользователем в чате. Конкретные оттенки, ширины и адаптивное размещение ещё проверяются отдельным макетом; основное приложение не изменено.

- Один переключатель темы для всего приложения и подложки карты. По умолчанию тёмная тема, выбор сохраняется между посещениями.
- Аналитические разделы ограничены по ширине и центрированы. Страница карты шире и рассчитана на постоянную информационную область.
- Header закреплён сверху: название раздела, территория, год/период, применимая группа и тема. Подробные фильтры — в панели карты; кеш/миллисекунды — в диагностике.
- Левое меню содержит полные названия готовых разделов. На узких экранах открывается по кнопке. Новое «Сравнение регионов» появится после готовности.
- Поиск и «Недавние» сейчас не добавляются. Пользователь отдельно попросил сохранить «Недавние» как возможный дальнейший вариант, не текущую задачу.
- Базовая плотность: обычные контролы 32px, header 40px. Вариант 32/36 сравнить в макете. Сенсорные зоны и конкретные отступы проверить отдельно; не утверждать общий переход всех desktop-кнопок на44px.

## Макет

prototypes/shell-layout-lab.html — отдельная лаборатория, Vite на5191. Использует текущие NativeOverview/NativeTime/NativeSeverity и реальные публичные summaries; стили темы изолированы в prototypes/shell-layout-lab.css. Состав графиков и формулы не меняются.

Есть сравнение32/40и32/36, max-width1040/1120/1190, обе темы, общий год Обзора/схемы карты, общая территория, общий период/группа Времени и Последствий и условий. Представления существующих компонентов сохраняются при переходах. Тема хранится отдельным ключом uad-shell-lab-theme, настройки опубликованного приложения не меняются.

Карта — SVG-схема с реальными BKG-контурами, без тайлов и загрузки точек. Число ДТП — реальная годовая сводка. Карточка условная; образцы переключателей участников не пересчитывают отбор. Это проверка оболочки, не реализация полноценной карты или drilldown-контракта пункта1.

prototypes/shell-layout-lab-responsive.html — документ с iframe390/768/1280px для проверки настоящих CSS-breakpoints без эмуляции сенсорного устройства. Верхняя панель настройки — только инструмент лаборатории.

## Проверка макета

Для фильтров участников согласованы SVG-иконки минус/нейтральный круг/плюс, общая легенда «без участия / любые / с участием» и подсказки. Выбранные состояния: оранжевый/нейтральный/бирюзовый; состояние также обозначено рамкой, не только цветом. Радиокнопки имеют полные доступные названия с типом участника. В макете проверено переключение, ESLint прошёл.

Уточнение пользователя: предложение двух колонок относилось к участникам в фильтрах карты. В макете они размещены в две колонки по три: название над трёхпозиционным переключателем. Проверено размещение в панели300px (260px полезной ширины) без горизонтального переполнения и переключение режима. Вариант двух колонок Обзора тоже оставлен для дальнейшего просмотра. Это пока образец фильтров, без пересчёта данных карты.

После просмотра пользователь согласовал ширину аналитики1190px и размеры32/36; они установлены по умолчанию в макете. Участники в Обзоре — две колонки по три строки (слева Pkw/велосипеды/пешеходы, справа мототранспорт/грузовые ТС/другие); полоса под названием и числом. На узком экране одна колонка. Перенос в основное приложение ещё не выполнен.

В браузере проверены обе темы, header 36px, переход Обзор → карта с Bayern/2024 → смена на2023 → Обзор, загрузка16контуров земель. Ширина и высота области карты не меняются при открытии/закрытии условной карточки. Проверены меню и раздел Времени в iframe390px, а также ширины768/1280px: документ не выходит за свою ширину (375/753/1265px с учётом полосы прокрутки). Это проверка CSS-компоновки, не тест физического мобильного устройства. Ошибок/предупреждений в консоли не обнаружено; ESLint нового JSX и git diff --check прошли.
