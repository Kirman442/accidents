# Единая оболочка UAD · шаг 08

Точка входа: `app.html` → `src/app/main.jsx` → AppShell. Отдельные legacy точки входа не используют её кеш.

## Жизненный цикл

AppShell читает manifest и accident_summaries, проверяет каталог и выбирает последний доступный год. FileLoader / RuntimePool создаются при первом запросе карты и закрываются при уничтожении корня. NativeMap подключается через React.lazy и после первого визита только скрывается. Active=false отключает обработку клавиатуры и picking, не освобождая результат, карточку и камеру. Бюджет LRU относится к учтённым буферам загрузчика; workers, GPU, DOM, агрегаты и библиотеки используют дополнительную память.

Экран обзора открывается по умолчанию. После шага 09 обзор — NativeOverview: контекст из AppShell, общий проверенный overview.json, нативные графики/таблицы. Посещённый обзор остаётся смонтированным и сохраняет представления. Аналитические frames времени/тяжести также сохраняются после первого визита; их агрегаты ещё хранятся внутри макетов.

## Контекст экранов

shell-state.js нормализует территорию 0–16, годы по каталогу, интервалы и допустимые группы. У обзора — территория/год; у времени и тяжести — территория/from/to/group; у карты — территория/год плюс собственные сложные фильтры.

Первый визит переносит только территорию и конечный год. Обычный возврат использует собственный контекст экрана. Явный переход из аналитики на карту выбирает конечный год периода и сбрасывает только группу участников к выбранному единственному флагу; месяцы, дни, часы, последствия и условия не изменяет. Это не обещание одинаковой численности аналитики и карты: карта может иметь дополнительные фильтры.

Обычные переходы используют pushState; изменение параметров текущего экрана — replaceState. popstate нормализует URL без перезагрузки. sessionStorage `uad-shell-v1` сохраняет контексты, ранее посещённые экраны, формат и бюджет; ранее посещённый экран не обязательно уже смонтирован после refresh. Камера/карточка/буферы сохраняются в текущей сессии приложения, а не после полного refresh. Отбор карты дополнительно использует прежнее собственное хранилище.

## Временный мост к аналитике

prepare-shell-prototypes.mjs копирует три HTML из prototypes, скрывает дублирующее меню/header и добавляет prototype-bridge.js. Исходные страницы не переписывает. public/prototypes и public/prototype-bridge.js игнорируются Git, готовятся prebuild/predev и попадают в dist.

AnalyticFrame проверяет same origin, точное contentWindow, screen и текущую ревизию. Сообщение ready инициирует отправку актуального контекста, не перезаписывая его начальным значением iframe. Каждая команда select получает возрастающую ревизию; context/navigate принимаются только для последней отправленной ревизии. Bridge обновляет лишь существующие значения select и вызывает исходный render. Встраиваемые страницы используют набор 2020–2025; перед расширением каталога надо синхронизировать их агрегаты и годы либо завершить перенос.

## План после шага 08

09 выполнен: нативный обзор и общий небольшой набор сводок/автопарка (README_09_step_Native_overview.md). Следом предложены 10: время/сезонность; 11: тяжесть/условия. Конкретные графики и оформление обсуждаются отдельно. Далее — подходящие границы и связи территории с картой, согласованные исследования, мобильные/сеть/публикация. Кандидаты из analytics-candidates.md не запускаются автоматически.


## Обзор после шага 09

AppShell запрашивает существующий analytics/overview.json один раз при первом визите в обзор, валидирует generation против manifest, отдельно обрабатывает ошибки/retry. NativeOverview больше не использует AnalyticFrame/bridge. Единственный header управляет годом/землёй; выбор земли внутри полос/таблицы обновляет этот же контекст. Динамика и сравнение земель имеют независимые показатели. Ограниченная область 1190 px, нижние колонки 45/55; карточки, последствия/участники и методика соответствуют согласованному макету. На narrow viewport одна колонка. Старые HTML-макеты/генератор сохранены для воспроизводимости и обсуждения; overview-embedded больше не монтируется в приложении.
