# Подключение границ земель и населения

После готовности оболочки приложение в свободное время загружает границы 16 земель с низким приоритетом. Карта использует общий кеш; население при этом не запрашивается. Контуры не перехватывают клики по ДТП; выбранная земля выделяется. В фильтрах карты есть переключатель «Границы земель».

Отдельная таблица населения содержит 16 земель и 400 районов/городов вне районов на 31.12.2025. `loadPopulation()` загружает её только по вызову будущего отчёта; сейчас существующая аналитика не изменена. `populationFor()` возвращает значение только для 2025 года, для остальных лет — null.

Исходная геометрия BKG на 01.01.2026 приведена к составу округов таблицы населения 2025: Hanau объединён с Main-Kinzig-Kreis, Trier и Trier-Saarburg раздельны. Контуры для отображения упрощены совместно, без округления координат; население хранится отдельно от геометрии.

Подготовка локальных данных:

```powershell
& 'M:\projekte\germany\UAD_data\.venv-boundaries\Scripts\python.exe' -X utf8 scripts/prepare_geography.py
```

Источник: `../UAD_data/population-boundaries-2025`. Генератор пишет `../UAD_data/geography-2025-v1`; штатные predev/prebuild копируют проверенные по SHA256 файлы в игнорируемую `public/geography`, затем Vite включает их в сборку. Для другой машины задайте `UAD_GEOGRAPHY_DATA` на папку подготовленного набора. Большие геометрические файлы в Git не добавляются. Сборка требует этот локальный набор; удалённый источник для него пока не настроен. Следующая ручная Netlify-сборка с этого компьютера включит файлы автоматически.

Набор не зависит от года ДТП и не входит в кеш полных записей карты. Ошибка фоновой загрузки не блокирует приложение; карта предлагает повторную загрузку контуров.
