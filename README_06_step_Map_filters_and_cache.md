# Шаг 06 — Map filters and cache

Дата: 2026-10-12. Ветка: codex/uad-file-benchmark. База: 5e9679b.

## Сделано

Подключены согласованные участники с тремя состояниями, множественный отбор месяцев/дней/периодов суток/последствий/освещения/покрытия, сезоны и Будни/Выходные. Пустой выбор — все, ИЛИ внутри категориального поля, И между полями и группами участников. Счётчики вариантов исключают свой фильтр. Нулевые невыбранные значения отключаются только после завершения расчёта; выбранные остаются снимаемыми. Все правила в docs/map-filters.md.

Workers держат исходные Arrow/Parquet-таблицы и возвращают Uint8-маски и точные счётчики. DeckGL DataFilterExtension применяет маски без новых буферов геометрии. Один запрос выполняется за раз, ожидающие изменения объединяются; устаревшие ответы игнорируются. FileLoader отклоняет ответы при изменении поколения выбора. Смена земли не перезагружает iframe, карту или данные. Годы сохраняются в существующем LRU; бюджет масок учтён. Последний год определяется по каталогу.

## Проверки

36 тестов прошли; ESLint шести изменённых модулей и сборка прошли. Известное предупреждение loaders.gl/browser-external spawn сохраняется. Независимая проверка: 60 сочетаний на реальных Arrow-колонках сверены с прямым перебором всех строк и всех фасетных счётчиков. Проверены OR, AND, Without, пустой результат, объединение земель, часы 0/23, кодировка дней, целостность каталогов с новым 2026 годом, отсутствие load-задач при запросах земель, отклонение результата старого года.

## Ограничения и доставка

На узком экране 32 МиБ вмещает примерно один год; возврат к вытесненному году загружает его снова. Для сравнения кеша нескольких лет выбирайте 100 МиБ. Карта и workers сохраняются при смене земли/года, но полный переход между отдельными HTML-экранами/перезагрузка освобождает бинарный кеш; значения фильтров сохраняются для вкладки. Карточка, карта нескольких лет, загрузка только одной земли и окончательное оформление не реализованы. Подложка требует сети.

Локальный архив полного исходного снимка: UAD_data/06_step_Map_filters_and_cache.zip. Данные, настройки, сборка и зависимости не включены. SHA256 и STEP_SNAPSHOT связывают архив с фактическим commit. Supabase, push и публикация не выполнялись.
