# Шаг 08 — App shell and shared cache

Дата: 2026-10-12. База: `eb0e870` (шаг 07). Ветка: `codex/uad-file-benchmark`.

## Результат

Новая точка входа — `app.html`: единое меню «Обзор», «Время и сезонность», «Тяжесть и условия», «Карта ДТП», общий закреплённый header и переходы без перезагрузки документа. Локальный адрес: http://127.0.0.1:5187/accidents/app.html.

Карта — нативный компонент приложения, подключаемый лениво. Один FileLoader, один пул из четырёх workers, один LRU кеш на всё время жизни приложения. При переходе в аналитику карта скрывается, но остаётся смонтированной: фильтры, камера, выделение, карточка и данные сохраняются. Неактивная карта не обрабатывает Esc и выбор точек.

При первом открытии обзора читаются каталог и небольшие сводки, без полных записей ДТП и без создания пула workers. Первый год карты выбирается из каталога. Бюджет буферов — 100 МиБ на десктопе / 32 МиБ при узком стартовом экране, с ручным переключением. Это лимит кеша буферов, не всей памяти браузера.

## Переходы и состояние

- Каждый раздел сохраняет собственные настройки. Первый визит наследует территорию и год / конец периода; группу участников автоматически не переносит.
- Обычное меню восстанавливает настройки выбранного раздела. «Показать на карте» явно переносит территорию, конечный год и одну группу участников; остальные фильтры карты сохраняет, о чём сообщает рядом с картой.
- URL, Back/Forward и sessionStorage согласованы. Полная перезагрузка сохраняет настройки, но создаёт новый кеш данных; прежние самостоятельные HTML тоже имеют отдельный кеш.
- Scroll позиции сохраняются на время жизни приложения. Параметры вложенных аналитических экранов передаются с проверкой origin, окна источника и ревизии; устаревшие ответы не перезаписывают новый выбор.

## Проверки

50 автоматических тестов прошли, включая прежние проверки загрузчика/фильтров/карточки и восемь новых сценариев состояния оболочки. ESLint изменённых модулей и production build прошли. Синтаксис bridge, генератора и встроенных скриптов трёх аналитических страниц проверен. Известное предупреждение loaders.gl о browser external spawn осталось прежним.

В браузере с реальными файлами проверены:

- Обзор и смена его территории без загрузки полных точек.
- Возврат из аналитики к карте 2025: тот же фильтр лёгких травм, 230 100 ДТП, та же карточка/кольцо/камера, кеш 27.16 МиБ, тот же готовый результат пересчёта.
- Esc в аналитике не снимает скрытое выделение карты.
- Время: Германия, 2020–2024, Pkw — 950 740 ДТП в макете. Явный переход на карту: 2024 + Pkw, фильтр лёгких травм сохранён, 169 153 ДТП. Кеш годов 2025 и 2024 — 53.88 МиБ.
- Тяжесть: Nordrhein-Westfalen, 2020–2025, велосипедисты — 109 796 ДТП в макете. Обычный возврат сохраняет карту Германия / 2024 / Pkw / лёгкие травмы.
- Back/Forward восстанавливает разделы без повторного создания карты. Ошибок console в финальном прогоне нет.

Снимки до/после возврата: `UAD_data/08-map-before.png`, `UAD_data/08-map-after.png`.

## Границы шага и далее

Аналитические экраны пока временные адаптеры сохранённых HTML-макетов с их реальными агрегатами. Они остаются смонтированными после первого визита, но ещё не используют общий механизм аналитических запросов. Исходные макеты охватывают текущие 2020–2025; добавление будущих лет потребует обновления аналитического набора / переноса экранов. Следующие шаги 09–11 — поочерёдный перенос обзора, времени и тяжести в компоненты приложения. UI/UX каждого раздела согласуем отдельно.

Границы земель/округов ещё не подключены. Схема Supabase, production, push и deploy не менялись. Старые страницы files.html / benchmark.html и самостоятельные макеты сохранены.

## Запуск и снимок

`npm run build` автоматически готовит три встраиваемых прототипа, затем `npm run preview -- --host 127.0.0.1 --port 5187 --strictPort`. Данные — в соседней UAD_data либо UAD_DATA_DIR; для внешнего хостинга нужен отдельно доступный опубликованный набор, одного исходного ZIP недостаточно.

Полный локальный снимок отслеживаемых исходников: `UAD_data/08_step_App_shell_and_shared_cache.zip`; commit записан в STEP_SNAPSHOT.txt, SHA-256 в соседнем .sha256. В архив не входят наборы данных, настройки, зависимости, dist и производные public/prototypes. Последние воспроизводятся prebuild/predev. Подробности: `docs/app-shell.md`.
