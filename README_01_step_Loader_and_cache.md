# Шаг 01 — Loader and cache

Дата: 2026-10-11. Ветка: `codex/uad-file-benchmark`. База шага: `255ac55`.

## Результат

Рабочая файловая страница `/accidents/files.html` читает выбранный год Unfallatlas 2020–2025. Основной источник — Arrow IPC + HTTP Brotli; альтернативный — Parquet ZSTD 10. Координаты и атрибуты хранятся вместе, каждая готовая земля появляется на карте. Все годы и форматы обслуживают четыре постоянных workers.

Подробные данные остальных лет подгружаются при выборе. Завершённые наборы сохраняются в кеше по версии данных, формату и году. Возврат к сохранённому году не вызывает загрузку или декодирование. HTTP-кеш версионируется контрольной суммой файла; повтор после вытеснения может использовать сохранённый браузером ответ.

LRU-кеш освобождает давно неиспользуемые наборы до начала новой загрузки. Обычный бюджет — 100 МиБ, облегчённый — 32 МиБ. На узком экране облегчённый режим выбирается при открытии; режим можно изменить вручную. Учитываются уникальные буферы, удерживаемые Arrow в workers, и ID/координаты, удерживаемые для карты в JavaScript. Это не общий пик памяти браузера: временные буферы декодирования, сборка мусора, WASM, GPU, тайлы и прочие объекты сверх бюджета.

Проверяются SHA-256, версия генерации, год, земля, число строк, уникальность внутренних ID, геометрия, домены атрибутов и исходные сводки. Ошибка оставляет год незавершённым; частичные наборы удаляются из workers. Быстрое переключение отменяет старую загрузку и не публикует запоздавшие результаты. Отдельные кнопки останавливают загрузку, повторяют её или очищают кеш.

Выбор земли работает с уже готовыми буферами. Расширенные фильтры участников, графики и сравнения нескольких лет относятся к следующим шагам.

## Структура и запуск

Проект: `M:\projekte\germany\UAD`. Данные и ZIP: `M:\projekte\germany\UAD_data`.

Локальный сервер автоматически выбирает последний `UAD_data/binary-2020-2025-*`. `UAD_DATA_DIR` задаёт другую папку данных, `UAD_BINARY_DATA` — конкретный экспорт. Для клиента `VITE_FILE_DATA_BASE_URL` задаёт HTTP-папку файлов; по умолчанию используется локальный маршрут `/accidents/__binary/`.

После `npm ci` и `npm run build` запустить `npm run preview -- --host 127.0.0.1 --port 5187 --strictPort`, затем открыть `http://127.0.0.1:5187/accidents/files.html`. Для файловой страницы настройки Supabase не требуются. Страница сравнения остаётся в `benchmark.html`; прежний эксперимент Supabase доступен через `index.html`.

Локальные скрипты подготовки бинарных данных теперь по умолчанию используют соседнюю папку `UAD_data`. Лаунчер принимает `-DataRoot` или переменную `UAD_DATA_DIR`. Старые скрипты переноса Supabase в этом шаге не запускаются; их исторические инструкции сохранены отдельно.

## Проверки и ограничения

24 Node-теста прошли, включая уникальные буферы Arrow, LRU, удержание в бюджете, возврат года из памяти, четыре параллельных задачи, отмену, ошибку/повтор и восстановление после отказа worker. Сборка и ESLint для изменённых JavaScript-файлов прошли. Сборка сохраняет прежнее предупреждение loaders.gl о browser-external spawn.

Браузер: 2025 Arrow — 273 007 ДТП, 26.64 МиБ; 2024 — 268 519 ДТП, 26.20 МиБ; 2023 — 269 048 ДТП, 26.26 МиБ; 2022 — 256 492 ДТП, 25.03 МиБ. Возврат 2025 подтверждён из памяти. После четвёртого года кеш составлял 77.93/100 МиБ и освободил наименее недавно использованный 2024. Снижение бюджета до 32 МиБ сохранило текущий 2022 и освободило остальные годы. При выборе 2025 в облегчённом режиме кеш занял 26.64/32 МиБ. Дополнительно прошли 4 Python-теста экспортёра и синтаксическая проверка PowerShell-лаунчеров. Хостинг Netlify и Edge Function относятся к отдельному шагу публикации. Текущий сервер отдаёт Arrow с `Content-Encoding: br`; альтернативный хост должен обеспечить совместимый ответ. Бюджет памяти относится к завершённым наборам и резерву новой загрузки, а не к принудительному ограничению памяти процесса.

Окончательная сборка проверена отдельно: Parquet 2025 в режиме 32 МиБ — те же 273 007 ДТП, 27.36 МиБ учитываемых буферов. Быстрое переключение 2020 → 2021 и остановка очистили незавершённую карту, сохранив завершённый Arrow 2025 в кеше. HTTP-запросы нового загрузчика используют SHA-256 в URL для отделения версий набора.

Также проверены выбор NRW (61 521 ДТП), очистка кеша до 0.00 МиБ и повторная загрузка после очистки. Снимок интерфейса сохраняется рядом с локальным ZIP в UAD_data.
