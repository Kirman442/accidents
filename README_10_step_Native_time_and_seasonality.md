# Шаг 10 — Время и сезонность в React

Дата: 2026-10-13. База: `7b9756d`. Ветка: `codex/uad-netlify-step08`.

## Результат

По прямому согласованию пользователя экран времени перенесён из iframe в React. Три карточки: итог ДТП, среднее за календарный день, максимум по месяцам. Три блока: сезонная линия, дни/часы, месяцы каждого года. По умолчанию — среднее за день, столбцы дней и таблица месяцев. Дополнительно доступны количество/доля, четыре периода суток/24 часа и числовая матрица месяцев. Ограниченная ширина1190px, мобильная одна колонка; сезонная линия без горизонтальной прокрутки, широкие таблицы и матрицы прокручиваются внутри панели.

Годовую динамику из лаборатории удалили по решению пользователя и записали кандидатом C20 в `docs/analytics-candidates.md`. Исторический макет сохранён в коммите7b9756d/архиве09_step_Time_year_trend.zip. Перестановка остаётся инструментом лаборатории и не добавлена в продуктовый экран. «Тяжесть и условия» остаётся iframe; следующий шаг11 требует обсуждения UI/UX.

## Состояние и данные

AppShell владеет территорией, периодом и группой участников. NativeTime после первого визита остаётся смонтированным: локальные представления и фильтры сохраняются при переходе в другой раздел. После reload сохраняется общий контекст, локальные представления возвращаются к default. Переход на карту использует прежний mapTransfer: территория, конечный год и единственная группа; остальные фильтры карты сохраняются.

Новый `public/analytics/time.json` — 383047 байт агрегатов из неизменённого `const data` исходного `prototypes/time-mockup.html`, с добавленными schema_version1 и generation из overview/каталога. Сохранены source и SHA256 исходных CSV за каждый год. Это шесть лет2020–2025 ×17 территорий ×7 групп, месяцы12 и совместные weekday×hour168. В Git нет подробных записей, Arrow/Parquet или credentials. Пересборка агрегатов из исходных данных не выполнялась. Обновляя каталог в будущем, нужно регенерировать этот снимок вместе с другими сводками.

Загрузка при первом визите, отдельные error/retry, валидация generation, размеров, целочисленных сумм, участников и совпадения каждой национальной ячейки с суммой земель. Для временного экрана карта и workers не загружаются.

Среднее месяца делится на календарные дни соответствующих месяцев периода; ячейка дня недели — на реальное число этих дней. Праздники входят в обычные дни недели. Доли дней/часов и сезонного профиля считаются от всех ДТП выбранного периода; месяцы отдельного года — от полного года. Локальные фильтры не меняют знаменатель, карточки и соседние блоки. Совместной сводки месяц×день×час нет; эта граница объяснена в UI. Зима — январь, февраль и декабрь одного календарного года.
