# Шаг 02 — Overview and fleet

Дата: 2026-10-11. Ветка: `codex/uad-file-benchmark`. База шага: `94c3ba1`.

## Результат

На файловой странице `/accidents/files.html` добавлен стартовый обзор Unfallatlas 2020–2025: динамика по годам, тяжесть ДТП, участники, сравнение 16 земель и ДТП с участием Pkw на 10 000 зарегистрированных Pkw. Выбор года и земли общий для карты и обзора. Земля сохраняется при смене года, источника и бюджета памяти. Показатель динамики переключается между абсолютным числом ДТП и нормированным показателем; таблица земель сортируется по этому показателю.

Обзор использует полные заранее рассчитанные годовые сводки, независимо от степени загрузки карты. Карточка возле карты отдельно подписана как число уже загруженных записей. Другие годы точек для обзора не скачиваются. Очистка/остановка кеша карты сохраняет обзор.

`public/analytics/overview.json` — небольшой публичный производный набор: 26 038 байт, 102 годовые сводки (Германия + 16 земель × 6 лет), 119 снимков автопарка (Германия + 16 земель × 7 дат 1 января 2020–2026). Только этот небольшой публичный набор отслеживается Git и входит в сборку и ZIP. Полные исходники, подготовленные таблицы и архивы по-прежнему находятся вне Git в `UAD_data`.

Источники: готовые `analytics/accident_summaries.json` и `analytics/fleet_snapshots.csv` из завершённого бинарного экспорта. Скрипт сверяет их SHA-256 с manifest, сохраняет контрольные суммы и generation в производном наборе, исключает районы и категорию other из региональных записей. Национальный автопарк берётся из национальной строки KBA, а не складывается из земель. Национальное число ДТП, тяжесть и участники проверяются против суммы земель. При несовпадении generation карты и обзора выводится отдельная ошибка; карта продолжает работать.

## Расчёт

Средний парк Pkw = (парк на 1 января выбранного года + парк на 1 января следующего года) / 2.

Показатель = число ДТП с участием Pkw / средний парк Pkw × 10 000. Для каждой земли используются её собственные снимки. В раскрывающейся таблице видны оба снимка и числитель. Отсутствующий снимок обозначается «Нет данных», без подмены нулём.

Участники могут пересекаться: ДТП с автомобилем и велосипедом входит в обе группы. Категории тяжести относятся к ДТП, а не количеству погибших/раненых людей. Показатель на автопарк не учитывает пробег, транзит и транспорт, зарегистрированный вне земли. Национальный автопарк KBA может отличаться от суммы земель из-за отдельной категории прочих регистраций. Произвольные комбинации фильтров будут рассчитываться по подробным данным в шаге 03; текущие сводки нельзя использовать для AND-пересечений.

## Подготовка и запуск

Подготовить/обновить набор командой:

```powershell
node scripts/prepare-overview.mjs M:/projekte/germany/UAD_data/binary-2020-2025-20261011-143536
```

Аргумент — конкретный завершённый экспорт. Необязательный второй аргумент задаёт выходной JSON; по умолчанию `public/analytics/overview.json`. Результат воспроизводим, временная дата в него не включается. После замены набора выполнить проверки и пересобрать приложение.

```powershell
npm test
npm run build
npm run preview -- --host 127.0.0.1 --port 5187 --strictPort
```

Страница: `http://127.0.0.1:5187/accidents/files.html`. Обзор поставляется из `public` независимо от маршрута подробных файлов `__binary`. Если подробные данные недоступны, обзор может работать отдельно. Настройки Supabase для файловой страницы не нужны. Сводки не входят в LRU-бюджет буферов карты; удерживаемый небольшой набор и объекты интерфейса относятся к дополнительной памяти браузера.

## Проверки

- Все 30 Node-тестов прошли: прежние 24 и 6 новых. Проверены целостность реального набора, все 102 расчёта, отсутствующий снимок, повтор снимка, ошибки поколения/земель/сумм, CSV с кавычками, исключение районов и контрольные суммы источников.
- Повторное формирование из реального внешнего экспорта полностью совпало с сохранённым JSON. Все 102 показателя дополнительно сверены с независимо подготовленным `analytics/land_year_indicators.csv`: ДТП, ДТП с Pkw, начало/конец, средний парк и отношение с допуском 1e-10.
- ESLint для изменённых файлов интерфейса прошёл. Производственная сборка прошла; сохраняется прежнее предупреждение loaders.gl о browser-external spawn.
- Браузер: Германия 2025 — 273 007 ДТП, 197 598 с Pkw, средний парк 49 412 826,5, показатель 39,99. NRW 2025 — 61 521 ДТП, 44 607 с Pkw, средний парк 10 647 601, показатель 41,89.
- Смена 2025 → 2020 сохранила NRW: 49 328 ДТП, 37 994 с Pkw, средний парк 10 299 071 и показатель 36,89. Переключение показателя изменило сортировку земель.
- Очистка во время загрузки оставила карту и кеш пустыми, обзор сохранился. Переключение Arrow/Parquet не меняет обзор. Мобильный просмотр 390 × 844: карточки в две колонки, секции в одну, широкие таблицы прокручиваются внутри; горизонтального переполнения страницы нет. Временный размер браузера восстановлен.
