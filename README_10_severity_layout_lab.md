## Изменения

- Панели ограничены1190px. Существующие четыре карточки, график тяжести, сравнение освещения/дороги, таблица и методика сохранены.
- Выбранный период на графике годов выделен фоном и подписан. Сохраняется контекст всех2020–2025.
- Рядом с долями категорий в отдельных условиях показаны числа ДТП и явное «Всего». Подписана область действия переключателя количества: только две отдельные панели.
- Сочетания получили понятный заголовок и объяснение знаменателя. В матрице процент подписан «тяжёлых», общее число — «Всего ДТП». Цветовая шкала0–50% и выше соответствует исходной насыщаемой шкале.
- Второе представление — точки: три группы состояний дороги, по три освещения, общая процентная ось от0. Цвет — освещение. Вся шкала адаптируется к максимуму выбранного среза, минимум20%, округление вверх до5п.п.; проценты выше50 не обрезаются.
- Ячейки/точки раскрывают числа трёх категорий в диалоге и не фильтруют экран. Общий фильтр территории/лет/участника обновляет оба представления. При переключении количества выше доли сочетаний сохраняются.
