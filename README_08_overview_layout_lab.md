# Подготовка UI/UX обзора после шага 08 — отдельный макет

Дата: 2026-10-12. База: `4c4d684`. Ветка: `codex/uad-netlify-step08`.

## Результат

Отдельная страница `prototypes/overview-layout-lab.html`, старт `http://127.0.0.1:5189/overview-layout-lab.html?region=5&year=2025`. Приложение, исходный overview-mockup, адаптеры iframe и публикация не изменены. Это обсуждение перед переносом обзора в React, а не выполненный шаг 09.

Три варианта:

- `variant=summary`: карточки → динамика → последствия и участники рядом → сравнение земель → источники.
- `variant=territory`: карточки → сравнение земель → динамика → последствия и участники → источники.
- `variant=fleet`: карточки → динамика показателя на 10 000 Pkw → таблица земель → последствия и участники → источники.

Основная область ограничена 1190 px вместе с внутренними отступами; альтернативная ширина 1440 px. Блоки можно двигать мышью за отдельную ручку, кнопками ↑/↓ и переключать между полной/половинной шириной. На мобильном блоки в один столбец. Выбор готового варианта или «Вернуть выбранный вариант» восстанавливает его раскладку. Ручная раскладка пока не сохраняется после reload; URL сохраняет вариант, год и территорию.

Динамика: линия, столбцы с нулевым началом или таблица всех шести лет. Для линии количества по земле используется индекс 2020=100 и сравнение с Германией; столбцы показывают абсолютное количество выбранной территории. Последствия: полоса состава + точные числа/доли. Участники: пересекающиеся группы, количество/доля. Земли: полосы или таблица, сортировка по выбранному в динамике показателю, кликабельный переход к обзору земли.

## Данные и методика

Встроенный объект данных скопирован из существующего overview-mockup без изменения. Использованы подготовленные сводки 2020–2025 и 119 снимков автопарка. Национальные и земельные значения выбираются отдельно, включая geography_level. Новые источники и подробные записи ДТП не загружаются.

Сохраняется различие числа ДТП и числа людей, пересечение групп участия, показатель Pkw по среднему двух концов года; он не трактуется как риск поездки. Название «Мототранспорт» обозначает существующий флаг krad, не новый показатель.

## Проверки и ограничения

Синтаксис скрипта проверен. В браузере проверены все три варианта, перестановка мышью и кнопками, reset, линия/6 столбцов/6 строк таблицы, смена территории/года. NRW2025: 61 521 ДТП, 434 с погибшими, 14.81% тяжёлых, 41.89 на 10 000 Pkw. Германия2020: 237 994 ДТП, без выдуманного предыдущего года. Console errors нет. При 390×844 document scrollWidth равен clientWidth; панель сравнения таблицы имеет локальную горизонтальную прокрутку.

Макет предназначен для согласования порядка, плотности и представлений. Новая общая тема интерфейса, перенос React, новые исследования, production/push/deploy не выполнялись. Навигация других разделов показана только как контекст, без имитации реализованных новых экранов. Полная accessibility/физический телефон — позже.

Запуск отдельного сервера: Python `-m http.server 5189 --bind 127.0.0.1 --directory M:/projekte/germany/UAD/prototypes`. В текущей сессии использована существующая UAD_data/.venv-binary. Исходники и документация сохраняются полным снимком `UAD_data/08_step_Overview_layout_lab.zip` с STEP_SNAPSHOT и SHA-256. Снимки: `08-overview-layout-lab-summary.jpg`, `08-overview-layout-lab-mobile.jpg`.
